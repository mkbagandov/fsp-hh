# ADR 0008. Раскрытие контактов через явные гранты

**Статус:** принято, 2026-10-10.

## Контекст
Правило ТЗ: контакты кандидата раскрываются только после принятия приглашения или
самостоятельного отклика. Нужна проверяемая реализация, а не разбросанные `if`.

## Решение
Контакты хранятся отдельно (`candidate_contacts`); факт раскрытия — запись `contact_grants`
(кандидат, компания, источник, время). Единственный путь чтения контактов для работодателя —
репозиторный метод `ContactsForCompany(candidate, company)`, который требует активного гранта
и пишет `audit_log`. Гранты создаются доменными событиями `invitation.accepted` и
`application.sent`. Регрессионные тесты покрывают «нет гранта → нет контактов» для всех
эндпоинтов, возвращающих карточку кандидата.

## Последствия
+ Правило проверяется одним запросом и тестами; удобно для аудита и объяснения жюри.
+ Отзыв гранта (концепция) — одно поле `revoked_at`.
− Дополнительная таблица и событие; принимается.
