# ADR 0004. Аутентификация: e-mail + Argon2id, JWT с ротацией refresh, OIDC-совместимость с Keycloak

**Статус:** принято, 2026-10-10.

## Контекст
ТЗ: регистрация по e-mail с подтверждением, безопасное хранение паролей и токенов, роли,
152-ФЗ; ФСП ID в будущем на Keycloak — совместимость приветствуется, способ авторизации за командой.

## Решение
- Собственная регистрация: e-mail + пароль (Argon2id), подтверждение кодом по почте, сброс пароля.
- Сессии: короткий access JWT (15 мин, HS256/EdDSA по конфигурации) + refresh-токен (14 дней)
  в `HttpOnly` cookie с ротацией и хранением хэша; отзыв по `revoked_at`.
- Роли в токене; проверки прав — в use case.
- OIDC-клиент для «Войти через ФСП ID» / «Привязать ФСП ID»: Authorization Code + PKCE, discovery,
  проверка подписи по JWKS. В хакатоне провайдер — `cmd/fspmock` с путями Keycloak; реальный Keycloak
  подключается конфигурацией. Профиль docker-compose `keycloak` с импортом realm — для демонстрации.

## Последствия
+ Переход на Keycloak ФСП не меняет код: только issuer, client id/secret.
+ Собственная регистрация остаётся для компаний и кандидатов без ФСП ID.
− Два пути входа — чуть больше тестов на связывание аккаунтов; принимается.
