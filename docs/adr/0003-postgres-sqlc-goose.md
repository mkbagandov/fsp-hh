# ADR 0003. PostgreSQL как единственное хранилище; sqlc и goose

**Статус:** принято, 2026-10-10.

## Контекст
Нужны транзакции (статусы приглашений, гранты контактов), агрегаты (карта категорий),
полнотекстовый и массивный поиск по навыкам. Локально PostgreSQL 18 уже установлен;
на стенде — контейнер. Соблазн использовать SQLite для «простого запуска» означал бы два диалекта.

## Решение
Только PostgreSQL (18 локально, образ `postgres:18` в compose). Запросы — SQL-файлы и
генерация типобезопасного кода через `sqlc` (pgx/v5). Миграции — `goose` в формате SQL,
встроены в бинарник и применяются при старте. Перечисления — `enum`, массивы — для навыков и форматов.

## Последствия
+ Производительность и простота: расчёт ранжирования в памяти по выборке категории, агрегаты в БД.
+ Один диалект, честные интеграционные тесты против реальной базы.
− Локальный запуск требует установленного PostgreSQL (инструкция в README); принимается.
