# ADR 0006. Тест: параметрические семейства заданий и адаптивный IRT

**Статус:** принято, 2026-10-10.

## Контекст
ТЗ: единый набор заданий утечёт; генерация нейросетью не гарантирует сопоставимую сложность.
Критерий оценки: устойчивость к утечке, стабильность при повторе, дискриминативность, соответствие экспертной оценке.

## Решение
Банк — семейства-генераторы на Go (`pkg/itembank`) с априорными параметрами 3PL; экземпляры
уникальны по seed, ответ вычисляется. Тест — адаптивный (`pkg/irt`): EAP-оценка θ, выбор по
информации Фишера с randomesque, балансом тем и контролем экспозиции, вероятностное правило
подтверждения грейда. Калибровка параметров по накопленным ответам и на синтетике.

## Альтернативы
- Фиксированные тесты по грейдам — отвергнуто: утечка.
- LLM-генерация под кандидата — отвергнуто: несопоставимость, нестабильность, зависимость от сети.
- Песочница с запуском кода — отложено: тяжело без Docker локально; форматы «что выведет код» и SQL-результат покрывают навык чтения кода.

## Последствия
+ Объяснимая и воспроизводимая шкала; утечка не даёт выигрыша; разные траектории у кандидатов.
− Авторинг семейств дороже, чем написание вопросов; смягчается стайлгайдом и параллельной генерацией.
