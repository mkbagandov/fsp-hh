# ADR 0005. LLM опциональна: единый интерфейс, в MVP эмулятор

**Статус:** принято, 2026-10-10.

## Контекст
Организаторы допускают облачные LLM, предпочитают открытые модели и возлагают риски 152-ФЗ
на команду. Ключей нет; продукт не должен зависеть от внешнего сервиса на демонстрации.
Решение пользователя: в MVP реальную модель не подключать, функции эмулировать, подключение подготовить.

## Решение
Интерфейс `internal/infrastructure/llm.Client` с операциями `Extract[T]` (структурное извлечение
по JSON-схеме), `Complete`, `Summarize`. Провайдеры: `mock` (детерминированный: правила +
справочник синонимов + шаблоны; умолчание), `openai_compat` (OpenRouter, Groq, Ollama),
`gigachat`. Все вызовы проходят через обезличивание (контакты и ФИО вырезаются), логируются
с идентификатором запроса; ответ LLM — всегда черновик, подтверждаемый пользователем.
Категоризация и ранжирование LLM не используют.

## Последствия
+ Демонстрация не зависит от сети и ключей; переключение — одна переменная окружения.
+ Контрактные тесты на обе ветки гарантируют одинаковый формат.
− Эмулятор извлекает хуже реальной модели на нестандартных текстах; принимается для MVP.
